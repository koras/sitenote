# sitenote

**Заметки по сайтам** — расширение Chrome для хранения небольших текстовых заметок рядом с веб-страницей. Кнопки заметок постоянно видны поверх сайта справа по центру. Нажатие на заметку или «Новая» открывает редактор рядом со списком, без перехода в боковую панель Chrome. Каждой заметке можно дать название и цвет; рядом с названием есть кнопка для копирования текста в буфер обмена.

Расширение запоминает время создания и последнего изменения заметки. Данные остаются в локальном хранилище текущего профиля Chrome: регистрация и сервер не нужны.

## Установка

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите эту папку.
4. Откройте или обновите обычную страницу сайта. Кнопки заметок появятся справа по центру автоматически.

Chrome запросит доступ к страницам сайтов, чтобы расширение могло показывать на них кнопки. Текст самих страниц расширение не считывает.

## Использование

- На обычном сайте кнопки заметок видны справа по центру страницы. Нажмите на название, чтобы открыть заметку.
- Нажмите **+ Новая**, чтобы открыть форму новой заметки. Введите название и текст, выберите цвет, затем нажмите **Сохранить**. Пустая заметка не создаётся.
- Изменения существующей заметки тоже применяются только после нажатия **Сохранить**. Кнопка **Отмена** закрывает форму без сохранения.
- Несохранённый черновик пропадёт при переходе на другую страницу или закрытии вкладки.
- Под каждой кнопкой заметки показаны дата и время создания либо последнего изменения.
- Кнопка `⧉` справа от названия копирует весь текст заметки. Часть текста можно выделить в редакторе и скопировать через `Ctrl+C`.
- Для удаления откройте сохранённую заметку, нажмите **Удалить заметку** внизу редактора и подтвердите действие.
- Заметки сохраняются только в этом профиле Chrome. Удаление расширения удалит его локальные данные.

Сайтом считается имя хоста без `www`: `example.com` и `www.example.com` имеют общие заметки, а `blog.example.com` — отдельные. Расширение показывает кнопки только на страницах `http://` и `https://`. На `chrome://`, `file://` и других служебных страницах оно не работает. После обновления расширения открытые вкладки нужно перезагрузить.

## Проверка логики

В папке расширения выполните `node --test tests/notes.test.mjs`.
