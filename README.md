# sitenote

**Заметки по сайтам** — расширение Chrome для хранения небольших текстовых заметок рядом с веб-страницей. Оно открывает блокнот в боковой панели браузера и автоматически показывает заметки активного сайта. Каждой заметке можно дать название и цвет; список названий расположен справа от редактора. Рядом с названием есть кнопка для копирования текста заметки в буфер обмена.

Расширение запоминает время создания и последнего изменения заметки. Данные остаются в локальном хранилище текущего профиля Chrome: регистрация и сервер не нужны.

## Установка

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите эту папку.
4. Закрепите «Заметки по сайтам» в меню расширений, чтобы кнопка была видна справа от адресной строки.

## Использование

- На обычном сайте нажмите кнопку расширения. В боковой панели появятся заметки этого сайта.
- Нажмите **+ Новая**, введите название и текст, выберите цвет. Изменения сохраняются автоматически.
- Кнопка `⧉` справа от названия копирует весь текст заметки. Часть текста можно выделить в редакторе и скопировать через `Ctrl+C`.
- Для удаления откройте заметку, нажмите **Удалить** и подтвердите действие.
- Заметки сохраняются только в этом профиле Chrome. Удаление расширения удалит его локальные данные.

Сайтом считается имя хоста без `www`: `example.com` и `www.example.com` имеют общие заметки, а `blog.example.com` — отдельные. На `chrome://`, `file://` и других служебных страницах заметки недоступны.

## Проверка логики

В папке расширения выполните `node --test tests/notes.test.mjs`.
